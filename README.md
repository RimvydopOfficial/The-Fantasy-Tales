#                                                           THE FANTASY TALES


#                                                             ABOUT GAME


The Fantasy Tales is a 2D fantasy RPG mobile game featuring Aether, 
a brave warrior exploring a mysterious world. 

Explore the map, navigate through towns and obstacles, and begin an adventure filled with exploration and danger.
